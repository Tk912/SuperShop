# משווה – השוואת מחירים עד הבית

השוואת מחירים בין חנויות בישראל ובחו"ל. העלות הסופית כוללת הנחות מועדון, קופונים, משלוח (ישיר או שילוח צד ג'), מע"מ ומכס.

```bash
npm install
npm start        # http://localhost:3000
npm test
```

## מבנה
| נתיב | תפקיד |
|---|---|
| `server/data/` | חנויות, מועדונים (בהצדעה, חבר…), קופונים, חברות שילוח, קטלוג – **נתוני דוגמה** |
| `server/pricing/landedCost.js` | מנוע העלות הסופית: בחירת שילוב ההנחות הטוב ביותר, כל מסלולי המשלוח, מסים |
| `server/pricing/taxConfig.js` | מע"מ 18%, פטור עד $75, מכס מעל $500 – ניתן לשינוי דרך משתני סביבה |
| `server/search/` | השלמה אוטומטית: עברית/אנגלית, קידומת, שגיאות כתיב, אותיות סופיות |
| `server/providers/` | ספקי מחירים: `demo` (תמיד), `serpapi` (Google Shopping), `ebay` (Browse API) |

## חיבור נתונים חיים
| משתנה | מה הוא עושה |
|---|---|
| `SEARCHAPI_KEY` | **מומלץ.** מחירים אמיתיים מ-Google Shopping לישראל דרך SearchApi.io: חיפוש מוצרים, ולכל מוצר כל החנויות עם מחיר, דמי משלוח וקישור ישיר. המפתח נשלח בכותרת `Authorization: Bearer` |
| `SERPAPI_KEY` | חלופה: אותם נתונים דרך SerpAPI (המפתח נשלח בכתובת הבקשה). כשמוגדרים שניהם, פועל רק SearchApi |
| `EBAY_CLIENT_ID`, `EBAY_CLIENT_SECRET` | eBay עם עלות משלוח אמיתית לישראל |
| `FORCE_DEMO=1` | מחירי הדוגמה ממשיכים לפעול גם כשיש ספק חי (בלי ההגדרה, הם כבויים כדי לא להתערבב עם מחירים אמיתיים) |
| `SAMPLE_DEALS=1` | מפעיל את נתוני המועדונים והקופונים לדוגמה גם על מחירים אמיתיים. כברירת מחדל הם פעילים רק במצב דמו |
| `SEARCHAPI_FIXTURE_DIR=test/fixtures/searchapi` | מצב הקלטה: הנתיב החי רץ על תשובות אמיתיות שמורות (6.11.2026), בלי רשת ובלי מפתח |

```bash
SEARCHAPI_KEY=<המפתח שלכם> npm start
```

### חיסכון במכסה
כל חיפוש וכל דף מוצר עולים בקשה אחת לספק. כל תשובה נשמרת במטמון דיסק (`.cache/`): חיפוש ל-12 שעות ודף מוצר ל-6 שעות.
מוצרים שעלו בחיפוש נשמרים במאגר מקומי, וההשלמה האוטומטית משתמשת בו בלי לפנות ל-API.

### היסטוריית מחירים
במצב חי, המחיר הסופי הזול ביותר לכל מוצר נרשם פעם ביום (`.cache/price-history.json`), לפי מחיר בסיס בלי הנחות אישיות.

## התראות מחיר (push)
האפליקציה שולחת לשרת את רשימת המעקב של המכשיר. השרת בודק מחירים כל `ALERTS_INTERVAL_HOURS` שעות ושולח התראה דרך שירות ה-push של Expo כאשר:
- המחיר הסופי הזול ביותר הגיע למחיר היעד, או
- אין יעד, והמחיר ירד ב-`ALERT_DROP_PCT` אחוזים לפחות (ברירת מחדל 3) ממחיר השמירה.

על אותו מחיר לא נשלחת התראה פעמיים, ומכשיר שהסיר את האפליקציה נמחק מהרשימה. כל מוצר נבדק פעם אחת בכל ריצה, גם כשכמה מכשירים עוקבים אחריו.

| משתנה | מה הוא עושה |
|---|---|
| `ALERTS_INTERVAL_HOURS` | כל כמה שעות לבדוק. 0 או לא מוגדר = כבוי (ב-Dockerfile: 6) |
| `ADMIN_TOKEN` | מפעיל את `POST /api/admin/check-alerts` עם `Authorization: Bearer <token>`, לבדיקה ידנית או מ-cron חיצוני |
| `EXPO_ACCESS_TOKEN` | אופציונלי: אם הפעלתם "Enhanced Security for Push" ב-Expo |

**מה צריך כדי שזה יעבוד בטלפון:**
1. להעלות את השרת לענן (יש `Dockerfile`; לחבר דיסק קבוע ל-`/data`). כדאי לבחור שירות שמריץ את השרת כל הזמן, כי שירות שמרדים אותו לא יריץ את הבדיקה התקופתית.
2. בתיקיית `mobile`: `npx eas-cli@latest init`. הפקודה יוצרת פרויקט EAS ומוסיפה ל-`app.json` את המזהה שנדרש ל-push token.
3. לבנות את האפליקציה עם `EXPO_PUBLIC_API_URL=<כתובת השרת>`. ב-Android צריך גם להגדיר FCM ב-EAS credentials.

## הנחות מועדונים וקופונים
כל ההנחות נמצאות ב-`server/data/deals.json` (או בקובץ ש-`DEALS_FILE` מצביע עליו, למשל `/data/deals.json` בשרת). לכל הנחה יש:
- **סטטוס:** `sample` (לדוגמה), `pending` (ממתין לאימות) או `verified` (מאומת).
- **מקור:** קישור לדף ההטבה. הנחה מאומתת חייבת מקור.
- **תאריך אימות:** נרשם אוטומטית בשמירה.
- **תאריך תפוגה:** אופציונלי.

**על מחירים אמיתיים חלות רק הנחות מאומתות שלא פג תוקפן.** במצב דמו חלות כולן.

**עריכה:** בדף `/admin.html` בשרת (צריך `ADMIN_TOKEN`). הדף כולל סינון "דורש תשומת לב", שמציג הנחות עם דיווחים, הנחות שממתינות לאימות והנחות שפג תוקפן.

**דיווחי משתמשים:** באפליקציה, ליד כל הנחה מאומתת, יש "לא עבד?". הדיווח נספר פעם אחת ליום לכל משתמש, ומסמן את ההנחה באדום בדף הניהול. אימות מחדש מאפס את הדיווחים.

## מה עוד חסר
- **להזין הנחות אמיתיות:** המערכת מוכנה, אבל מישהו צריך לאמת אותן מול אתרי המועדונים ולהזין דרך דף הניהול. לרוב המועדונים אין ממשק פתוח, ולכן כדאי לבדוק שיתוף פעולה או רשת שותפים.
- **העלאת השרת לענן** וחיבור לפרויקט EAS, כדי שההתראות יגיעו לטלפונים. ראו "התראות מחיר".

ספק חדש = מודול עם `enabled()` ו-`offersFor(product)` (ואופציונלית `searchProducts(query)`), שנרשם ב-`server/providers/index.js`.
